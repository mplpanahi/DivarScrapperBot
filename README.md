# Divar Scraper Bot (ربات استخراج اطلاعات دیوار)

یک ربات پیشرفته و هوشمند برای جمع‌آوری مشخصات و شماره تماس آگهی‌های سایت دیوار با رابط کاربری تحت وب، قابلیت مدیریت چند حساب کاربری و خروجی اکسل.

## ویژگی‌ها (Features)
- 🌐 **رابط کاربری مدرن تحت وب (Web Dashboard):** کنترل آسان تمامی تنظیمات، مشاهده وضعیت و لاگ‌ها به صورت زنده
- 🔗 **پشتیبانی از لینک مستقیم دسته‌بندی:** استخراج خودکار شهر و دسته‌بندی از لینک‌هایی مانند `https://divar.ir/s/mashhad/vehicles`
- 📱 **مدیریت چند اکانت (Multi-Account Rotation):** ورود با چندین شماره موبایل با تایید پیامک (OTP) و چرخش خودکار بین اکانت‌ها برای گذر از محدودیت سقف روزانه شماره تماس
- ⚡ **استخراج سریع با API رسمی دیوار:** دریافت صدها آگهی در چند ثانیه بدون نیاز به مرورگرهای سنگین
- ⏳ **تاخیر هوشمند و ضد مسدودی (Anti-Detection & Smart Delays):** جلوگیری از بلاک شدن اکانت‌ها و خطا در فایروال دیوار
- 📊 **خروجی اکسل و دیتابیس:** ذخیره بلادرنگ در SQLite و خروجی با فرمت‌های Excel (.xlsx) و CSV و JSON
- 🔄 **قابلیت ادامه خودکار (Resume Support):** ثبت آگهی‌های دیده‌شده و عدم ارسال درخواست تکراری

## نصب و راه‌اندازی (Installation)

```bash
# نصب پیش‌نیازها
pip install -r requirements.txt

# اجرای برنامه
python app.py
```
سپس مرورگر را باز کرده و به آدرس `http://localhost:8000` مراجعه نمایید.
